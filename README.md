## 🚀 Projeto em destaque

### 🍔 Lanchonete Automatizada

API REST desenvolvida com **Java e Spring Boot** para gerenciamento de uma lanchonete.

**Funcionalidades do projeto:**

- Gerenciamento de produtos.
- Controle de estoque.
- Cadastro e gerenciamento de pedidos.
- Gerenciamento de comandas.
- Regras de negócio para pagamentos.
- Persistência de dados com MySQL.

**Tecnologias:** Java, Spring Boot, MySQL, Maven e Docker.
